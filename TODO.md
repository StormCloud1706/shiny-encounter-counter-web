# Shiny Counter Project Checklist

Work in small, explained steps. The user runs commands and writes app code;
the assistant provides guidance and reviews. This checklist is a roadmap,
not a commitment to build everything at once.

## Setup and Git Practice

- [x] Create the React/Vite starter and open it in the browser.
- [x] Confirm Git is installed.
- [x] Initialise a local Git repository on main.
- [x] Commit the starter project and this checklist.
- [x] Create a GitHub repository and push the initial commit.
- [ ] Practise a feature branch, focused commits, and a pull request.

## App Features

- [ ] Build a single-hunt layout with a Pokemon selection.
- [ ] Add increment, decrement (never below zero), and confirmed reset.
- [ ] Save and restore hunts using localStorage.
- [ ] Support multiple active hunts and completed hunts.
- [ ] Add Pokemon sprites with loading and error states.
- [ ] Add game, hunting method, and relevant bonus selections.
- [ ] Calculate odds using verified rules and documented sources.
- [ ] Export hunts to a JSON file for backup.
- [ ] Import hunts with data validation and clear duplicate handling.
- [ ] Add light/dark mode and remember the preference.
- [ ] Make the app usable on mobile and with a keyboard.

## Quality and Portfolio

- [ ] Introduce automated tests alongside the first counter behaviour.
- [ ] Test saving/restoring, import/export, and odds as they are added.
- [ ] Add a browser test for the main hunting workflow.
- [ ] Run automated checks on GitHub for pull requests.
- [ ] Replace the starter README with setup, decisions, limitations, and sources.
- [ ] Publish a live demo.

## Possible Later Phase

- [ ] Evaluate accounts and a backend for cross-device synchronisation.
